# 登录与节点管理修复同步

本次将已验证的登录、任意门转发和节点分享修复同步到 `main`，并更新后端内嵌前端。此提交不创建新版本标签或 Release。

## 登录

- 等待品牌、登录方式、验证码和静默登录状态就绪后显示表单，避免先显示不完整界面再重新布局。
- 用户名优先匹配；唯一邮箱可忽略大小写登录，重复邮箱拒绝匹配。登录限流和后续验证归属统一到实际账号。
- 正确凭据对应的停用账号显示停用提示；错误凭据仍显示账号或密码错误，保留不同拒绝原因。

## 节点与转发

- 区分任意门入口与目标节点的客户端协议；转发入口在列表中跟随绑定目标分组显示。
- 编辑转发入口时选择现有受管节点，同步实际转发、继承订阅配置和持久化绑定；旧页面冲突会被拒绝。
- 新选择默认使用服务器 IP。域名模式读取服务器管理中的节点域名，已有值只读；未配置时可输入，并提示保存后同步到服务器管理。
- 域名、绑定、订阅配置和远端入站意图事务保存。只有远端确认后才报告成功；失败执行补偿并明确提示未确认状态。
- 节点二维码和分享链接读取最新服务器节点域名，保留端口及当前用户凭据。转发入口使用入口服务器域名；中转等已选择的特殊入口保持原路径。
- 二维码弹窗及链接框扩大，链接字号增至 14px，支持换行、选择与滚动；复制、二维码和下载 PNG 使用同一链接。
