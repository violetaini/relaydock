# 更新日志

## v0.6.29 (2026-11-27)

### 本次更新
- 套餐管理支持保留原订阅：在套餐订阅规则模板中增加「保留原订阅」选项，启用后直接输出原始订阅内容，跳过规则模板覆盖。
- 套餐配置模块交互优化：关联节点、关联订阅、服务器节点授权、转发线路授权 4 大模块默认折叠收起，支持清晰按需展开。
- 套餐「全选 / 取消全选」操作语义统一：将原有「选择当前结果 / 取消当前结果」按钮重命名为「全选 / 取消全选」。
- 关联订阅流量控制全面补全：为套餐内的关联订阅引入 Tier 2 模块总额度配额以及 Tier 3 单订阅自定义倍率、流量上限、限速与设备数控制，后端即时级联校验与配额限制执行器（Limiter Enforcer）全面生效。
- 用户管理服务授权 UI 焕新：重构用户列表「服务授权」展示样式，清晰区分套餐授权徽章与自定义独立授权徽章，并配合高对比度资源类型标签（服务器/节点/订阅）清晰显示。
- 用户列表排序与正倒序解耦：将排序字段下拉选单（注册顺序、姓名顺序、用量顺序、到期顺序）与正倒序切换按钮解耦，支持一键在升序与降序之间快速切换，后端配套支持 `order=asc|desc`。
- 用户过滤选单交互排版优化：为多选下拉框内的搜索输入框添加水平内边距，消除文字贴紧边框的问题。
- 系统设置界面视觉净化：移除各设置分頁（基础设置、订阅设置、安全设置、通知设置、系统维护等）顶部的冗余群组大标题，消除视觉噪点，统一布局风格。
- 用户管理配额与概览统计修复：修正用户概览与配额统计中订阅类型资源（subscription kind）的计数与限额关联。
- 嵌入式前端快照全面同步：更新 Vite 编译前端生产产物并同步打包至控制器二进制。

### 影响与兼容性
- 控制端主程序与前端控制台版本统一升级至 v0.6.29，API Contract 保持为 3。
- 数据库结构完全向后兼容，已有套餐、订阅、用户配额及授权数据平滑迁移。
- 排序接口向后兼容，未指定 order 参数时保持默认排序规则。

## 更新版本
- 裸机与 systemd 服务：使用面板内置在线更新或运行更新脚本升至 v0.6.29，数据目录及现有配置自动保留。
- Docker 容器部署：拉取并使用 ghcr.io/violetaini/relaydock:0.6.29，映射既有数据卷即可。
- 独立前端部署：采用配套 release bundle 中的 relaydock-web.tar.gz 替换 Web 静态资源。

## 操作方法
1. 在套餐编辑中，订阅规则模板选择「保留原订阅」可直接透传原始订阅，展开「关联订阅」模块可为单个订阅配置专属流量上限与速率限制。
2. 在用户管理中，通过列表右上角排序下拉框选择排序维度，并点击正序/倒序按钮即可快速倒换排列顺序。
3. 在系统设置中，各子分頁直接呈现设置卡片与操作表单，操作流程更加紧凑直观。
