# 更新日志

## v0.6.31 (2026-11-28)

### 本次更新
- 全面补齐订阅计费倍率、套餐到期与流量配额耗尽即时停服闭环：统一订阅与短链计费统计口径，确保套餐过期、总流量或分模块/单节点/订阅配额超限后立即拒绝签发并向节点下发停用与限速快照。
- 修复同端口与跨端口精准限速链路：
  - 控制面 `BuildLimiterConfigForServer` 改用同 `inbound_tag` 物理/routed 节点列表与精确 `RoutedNodeID` 映射，解决同端口多节点/多套餐互相覆盖的问题；
  - `PushToAllServersForPackage` 与 `PushToAllServersForUser` 补齐托管服务器授权及转发入口服务器推送，并修正套餐更新中转发授权重算与推送的顺序竞争；
  - 配套升级嵌入式 Agent 至 v0.4.13，修复 VLESS XTLS-Vision 内核 `splice` 绕过限速、按 `(tag, email)` 隔离 `AutoSpeed` 状态，以及按入站精确下发与清空动态限速规则。
- 新增计费/配额停止及同端口、不同端口、同服务器限速验收测试。

### 影响与兼容性
- 控制端主程序与前端控制台同步升级至 v0.6.31，配套 Agent 源码锁定为 v0.4.13（`5d908fb814f450db59df41e0c5608a73a5307daa`），API Contract 保持为 3。
- 与既有配置与数据库完全兼容，升级后自动按最新计费与限速逻辑生效；建议同步将边缘节点 Agent 升级至 v0.4.13 以获得完整的同端口/跨端口及 Vision 限速修复。

## 更新版本
- 裸机与 systemd 服务：使用面板内置在线更新或运行更新脚本升级至 v0.6.31，数据目录及现有配置自动保留。
- Docker 容器部署：拉取并使用 `ghcr.io/violetaini/relaydock:0.6.31`，映射既有数据卷即可。
- 独立前端部署：采用配套 release bundle 中的 `relaydock-web.tar.gz` 替换 Web 静态资源。

## 操作方法
1. 通过面板「系统设置 -> 维护 -> 立即更新」或 Docker 镜像升级主控端至 v0.6.31。
2. 主控升级完成后，建议在「服务器管理」中将各节点 Agent 更新至 v0.4.13。
