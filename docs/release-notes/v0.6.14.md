# 更新日志

## v0.6.14 (2026-08-05)

### 本次更新
- 修复 Agent 上报 `scan_result` 时后端同步执行 Xray 对账造成的 WebSocket 读循环死锁。对账现在异步执行，仍可通过同一连接正常接收 RPC 回包，重连后会真正完成幽灵入站清理。
- 修复 WireGuard 节点私钥在启动迁移阶段尚未解密时被延后、但主控启动后没有补回数据库权威入站的问题。私钥初始化完成后会幂等重跑当前快照回填，保留删除墓碑，不会接纳未授权入站。
- 当 Agent 的完整 Xray 配置没有包含 confdir 入站时，对账会使用 Agent 入站清单补齐“已有数据库节点”定义；观察字段会被清除，数据库节点授权规则不变。

### 影响与兼容性
- 本版本是 `v0.6.13` 的兼容性修复版本，已有节点、用户授权和 Agent 升级策略不变。
- 升级后首次重连会执行一次数据库入站对账；合法的数据库节点会保留，未在“节点管理”中的运行时入站会被移除。这个过程使用入站热更新，不会因此重启 Xray。
- 远程服务器仍需由管理员逐台确认升级 Agent `v0.4.10`，面板不会自动替换用户管理的 Xray 内核。

## 更新版本
- 裸机 / systemd：在面板“系统设置 -> 系统更新”检查并更新到 `v0.6.14`。
- Docker：在宿主机执行 `docker compose pull && docker compose up -d`。

## 操作方法
1. 更新前保留可恢复的数据库备份，并确认服务器可以访问 GitHub Release 下载域名。
2. 更新完成后打开“节点管理”，确认服务器代理节点仍完整；需要保留的入站必须有对应数据库节点。
3. 等待服务器 Agent 重连，查看节点状态和 Xray 入站，确认幽灵入站已经消失且合法 WireGuard 入站仍在。
