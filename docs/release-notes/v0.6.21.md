# 更新日志

## v0.6.21 (2026-11-15)

### 本次更新
- 加固 OIDC：验证 RS256/JWKS 签名，检查必要的签发者、受众、有效期和 nonce，增加 PKCE S256。
- 60 秒单次授权兑换码绑定发起登录的浏览器，兑换响应禁止缓存；移除旧版 URL 会话令牌接收逻辑。
- 玻璃卡片登录页成为默认样式，经典双栏布局仍可选择。标题、副标题、品牌图片、字体和自动 OIDC 检测可在后台配置。
- 支持内置渐变、固定壁纸和随机背景，可配置图片列表或随机图片接口；输入时保持背景稳定，加载失败自动回退。
- 登录成功直接进入后台；SSO 回调兑换期间不再闪现公开探针页，并清除遗留的探针预览参数。

### 影响与兼容性
- 控制端及前端版本为 v0.6.21，API contract 保持 1。
- 品牌、背景和自动登录选项保存在现有数据库中。升级保留数据目录及服务配置，不需要重置账号或重新绑定身份。
- OIDC 提供商须提供 RS256 签名 ID Token 与有效 JWKS；自动检测需支持 prompt=none。未启用自动检测时保留手动登录。
- 经典字体选项使用客户端已有的华文楷体和 Times New Roman，不附带商业字体文件。
- 旧版 oauth_token URL 登录方式不再接受，请同时升级前后端。

## 更新版本
- 现有安装可使用项目升级工具更新至 v0.6.21；升级前备份数据库及持久资源，保留服务配置。
- 使用 Docker 的部署选择 ghcr.io/violetaini/relaydock:0.6.21，并保留原有数据卷。
- 独立前端使用本次后端 Release 配套的 relaydock-web.tar.gz；同一版本同时提供前端源码仓库的构建包。

## 操作方法
1. 在「设置 → 基础设置 → 项目品牌」配置登录页风格、文案、字体与自动 OIDC 检测。
2. 在「界面外观」选择背景模式，并填写固定壁纸或随机图片地址。
3. 在快捷登录设置中登记身份提供商及固定回调地址，按既有规则绑定本地账号。
