# 更新日志

## v0.6.26 (2026-11-20)

### 本次更新
- 优化 DDNS 证书与域名关联交互：彻底解决证书数量较多时下拉列表过长的问题，将 DDNS 提供商选择器精简为「自动匹配」与具体「DNS 提供商」，永不膨胀。
- 智能证书快捷引用：在节点域名输入框处提供「快捷填入根域名」标签（证书较少时直接展示 Chips）与「从已签发证书选取」浮层（证书较多时提供带即时搜索框的弹出层），一键自动带入子域名，杜绝手动输入拼写错误。
- IP 地址智能识别与引导：当在节点域名处输入 IP 地址（如 158.51.111.32）时，实时提供醒目引导提示，告知 DDNS 必须使用完整域名以便动态更新解析。
- 手动上传证书全生命周期关联合规：开放手动上传证书（PEM/KEY）选择与修改关联的 DNS 提供商，支持 DDNS 自动复用。
- 前端与内嵌快照全面同步：更新内嵌前端资源，保证单机交付与嵌入式发布一致性。

### 影响与兼容性
- 控制端主程序与前端控制台版本统一升级至 v0.6.26，API Contract 保持为 1。
- 数据库结构向下兼容，已有证书及服务器的 DDNS 配置完全无缝兼容。
- 现有 DDNS 定时解析任务不受影响，保持高效稳定运行。

## 更新版本
- 裸机与 systemd 服务：使用面板内置在线更新或运行更新脚本升至 v0.6.26，数据目录及现有配置自动保留。
- Docker 容器部署：拉取并使用 ghcr.io/violetaini/relaydock:0.6.26，映射既有数据卷即可。
- 独立前端部署：采用配套 release bundle 中的 relaydock-web.tar.gz 替换 Web 静态资源。

## 操作方法
1. 管理员进入「服务器管理」，点击「添加服务器」或编辑现有服务器。
2. 切换至「启用本面板 DDNS 服务的域名」，可直接点击下方已有证书的快捷标签或通过搜索框挑选证书，自动生成子域名。
3. 若输入的是 IP 地址，系统将自动提示并指引更正为域名；右侧 DDNS 提供商下拉框保持精简清爽，支持自动匹配或手动指定 DNS 服务商。
