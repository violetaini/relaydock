# 更新日志

## v0.6.12 (2026-08-04)

### 本次更新
- 服务器卡片、服务器列表和公开测速页的国家/地区标识改为随前端发布包提供的 SVG 国旗，不再依赖浏览器或操作系统是否安装 Emoji 国旗字体。
- 香港、美国、日本等已识别国家/地区码会显示对应的矢量国旗；无法识别的代码会显示中性的地球图标，不会再把两位代码当作旗帜显示。
- 正式产品发布包已同步新的前端静态资源，面板“系统更新”会校验并原子切换控制端和受管网页到同一版本。

### 影响与兼容性
- 本次不改变 API 协议、节点配置、订阅、Agent、Xray、Mihomo 或测速端的行为。
- 浏览器会自动下载新的带哈希前端资源；如页面仍保留旧国旗显示，可刷新页面以完成资源更新。
- Docker 部署仍需在宿主机执行镜像更新，不能在容器内执行面板原地更新。

## 更新版本
- 裸机 / systemd：在面板“系统设置 -> 系统更新”检查并更新到 `v0.6.12`。
- Docker：在宿主机执行 `docker compose pull && docker compose up -d`。

## 操作方法
1. 更新前完成可恢复的加密备份，并确认服务器可以访问 GitHub Release 下载域名。
2. 裸机 / systemd 部署在面板执行完整更新，等待事务、后端健康检查和网页版本检查全部完成。
3. 更新完成后刷新服务器列表或公开测速页，确认国家/地区标识已显示为 SVG 国旗。
4. Docker 部署在宿主机拉取并重建镜像，不要在容器内点击原地更新。

## 验证
- 前端已通过 TypeScript 类型检查、SVG 国旗及服务页定向单元测试、生产构建和公开测速页浏览器验证。
- GitHub 发布工作流会在创建 Release 前再次执行完整 Go 测试、发布包契约校验、资产哈希校验和网页元数据校验。
