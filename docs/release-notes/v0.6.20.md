# 更新日志

## v0.6.20 (2026-11-15)

### 本次更新
- 杜绝回调 URL 暴露令牌：全面移除 `/?oauth_token=...` 明文重定向，引入短时（60 秒）单次有效授权兑换码 `oauth_code`，并新增安全兑换端点 `POST /api/public/oauth/exchange`，兑换后立即销毁，杜绝重放与凭证外泄。
- 加固 OIDC 身份验证：严格校验 OIDC JWT `id_token` 的签发者（`iss`）、受众（`aud`）、有效期（`exp`，支持 120 秒容差）与防重放随机数（`nonce`），并确保 `id_token` 与 `userinfo` 主体（`sub`）完全一致。
- 邮箱自动关联防劫持保护：在启用 `AutoLinkEmail` 时强制校验第三方身份提供商的 `email_verified == true`，未通过验证的邮箱严格拒绝自动关联本地已有账号，杜绝账号劫持漏洞。
- OIDC 静默登录检测支持：授权跳转支持 `?silent=true` 并附加 `prompt=none`；在上游反馈 `login_required` / `interaction_required` / `consent_required` 等未登录状态时，后端优雅重定向至 `/?sso_silent=guest`，前端自动清理 URL 参数并保持在控制台登录页，绝不无故强制跳转或报错。

### 影响与兼容性
- 控制端主程序与内嵌 Web 前端全面升级至 v0.6.20。
- 保持向后兼容：前端在接收到旧版 `oauth_token` 时仍可正常兼容相应登录流程。
- 现有线上登录配置与本地密码验证不受任何影响。

## 更新版本
- 裸机 / systemd：执行 `curl -fsSL https://raw.githubusercontent.com/violetaini/relaydock/main/quick-install.sh | bash` 或使用 `relaydock update` 升级至 v0.6.20。
- 线上实例：国际端 RelayDock (`https://relay.chitanda.net`) 已完成无损平滑热更新至 v0.6.20。

## 操作方法
1. 管理员可进入「系统设置」->「快捷登录与 SSO」配置 GitHub、Google 或 OIDC 提供商。
2. 登录页面支持常规账号密码登录与第三方身份验证共存。
3. 未登录用户访问登录页时保持常态输入框，不被强制中断。
