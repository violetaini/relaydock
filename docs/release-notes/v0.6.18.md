# 更新日志

## v0.6.18 (2026-11-14)

### 本次更新
- 推出全新的一键极简安装脚本与现代化交互式 CLI 管理控制台（relaydock），借鉴哆啦A梦面板、妙妙屋 X 与 Komari 设计；支持一键查看服务状态、端口管理、启停重载、日志追踪、修改密码与事务安全回滚。
- 套餐管理与服务授权重构：套餐关联节点现在严格限制为多用户多路复用协议节点（如 VLESS/VMess/Trojan/Shadowsocks 等支持用户凭据隔离的协议），并在前端套餐编辑器中自动过滤并拒绝对接非多用户协议节点，彻底杜绝单用户节点被多人同时覆盖的安全与计费隐患。
- 节点与服务器管理交互大幅简化：重构添加服务器表单，公网 IPv4 与 DDNS 域名收折至高级设置手风琴，默认启用内置 Xray 全托管；引入借鉴自哪吒/Komari 的在线心跳雷达探测，即时反馈 Agent 连通性。
- 全局 UI 视觉排版与字号优化：全面放大套餐模板卡片、服务器监控指标、备注标签及转发管理等工作台的字号，移除移动端与桌面端不必要的水平滚动条，大幅提升可读性与操作对比度。
- Agent 端同步升级至 v0.4.11：新增端口可用性检测接口，内置自定义 geodata 种子数据，完善服务端令牌轮换持久化与 3x-ui 检测适配。

### 影响与兼容性
- 控制端主程序、内嵌 Web 前端、安装管理工具与 Agent 二进制版本全面升级至 v0.6.18 与 v0.4.11。
- 套餐节点协议限制生效后，已有的历史套餐若包含非多用户协议节点不会被强制清退，但修改或新建套餐时将严格执行多用户协议校验。
- 采用全新的 /usr/local/bin/relaydock 命令作为系统级统一管理入口，旧版裸机服务完全无缝兼容。

## 更新版本
- 裸机 / systemd：执行 curl -fsSL https://raw.githubusercontent.com/violetaini/relaydock/main/quick-install.sh | bash 或使用 relaydock 菜单选择更新，脚本将自动拉取 GitHub 最新发布的 v0.6.18 预编译包进行无损热更新。
- Docker：在宿主机执行 docker compose pull && docker compose up -d 拉取 ghcr.io/violetaini/relaydock:0.6.18 镜像。

## 操作方法
1. 更新前建议执行 /usr/local/bin/relaydock backup 或保留 /opt/relaydock/data/arcway.db 数据库备份。
2. 运行一键安装或更新脚本，等待控制端二进制、内嵌前端及系统服务平滑重启。
3. 登录面板后，进入「服务器管理」检查各受管节点状态，点击「升级 Agent」将受管端同步更新至最新版本。
4. 检查套餐模板管理与转发管理，确认新版字号排版与心跳雷达正常工作。
