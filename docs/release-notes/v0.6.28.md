# 更新日志

## v0.6.28 (2026-11-23)

### 本次更新
- 转发支持自定义公网目标：创建与编辑用户转发时支持填入自定义公网域名或 IP 及目标端口，并由出口节点直接转发至公网目标。
- 节点管理深度集成隧道转发：节点列表中将隧道转发与对应目标节点绑定显示，支持一键二维码导入，协议标识简化优化为「TU」。
- 隧道入口独立测延迟：节点管理与转发列表支持针对隧道转发入口执行独立延迟测试，获取真实的端到端隧道网络延时。
- 隧道授权与套餐批量管理强化：用户隧道授权支持多隧道批量勾选、双向隧道自动聚合授权，管理员默认拥有全局隧道权限且界面免冗余显示。
- 套餐隧道授权保护：套餐派生的用户隧道授权在隧道管理界面禁止随意篡改并明确标记来源，确保计费与授权规则一致。
- 交互与布局视觉优化：套餐管理与授权弹窗中的服务器/隧道列表支持搜索筛选与最大高度滚动，优化双向对称标签与表头边距视觉效果。
- 嵌入式前端快照全面同步：更新 Vite 编译前端生产产物并同步打包至控制端二进制。

### 影响与兼容性
- 控制端主程序与前端控制台版本统一升级至 v0.6.28，API Contract 保持为 1。
- 数据库结构向下兼容，已有转发规则、隧道配置、套餐及用户授权完全无缝兼容。
- 自定义公网目标转发要求出口节点拥有目标网络的出网访问能力。

## 更新版本
- 裸机与 systemd 服务：使用面板内置在线更新或运行更新脚本升至 v0.6.28，数据目录及现有配置自动保留。
- Docker 容器部署：拉取并使用 ghcr.io/violetaini/relaydock:0.6.28，映射既有数据卷即可。
- 独立前端部署：采用配套 release bundle 中的 relaydock-web.tar.gz 替换 Web 静态资源。

## 操作方法
1. 创建转发时，在目标选择步骤可切换「托管节点」或「自定义公网目标」，输入目标地址及端口即可完成转发。
2. 节点管理中可直接查看关联的隧道转发，点击测延迟即可测试隧道入口连通性，点击二维码可快速导入客户端。
3. 授权隧道时，可在弹窗中多选隧道并一次性完成授权，双向对称隧道只需单次点击即可同时开通双向。
