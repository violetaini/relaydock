# 更新日志

## v0.6.27 (2026-11-21)

### 本次更新
- 探针外观与背景自定义增强：支持登录页与公开探针外观背景无缝共享与模式专属切换，以 Bing 作为随机壁纸默认来源，背景输入更直观。
- 流量仪表盘优化：针对不限流量的服务器与节点，优化流量进度条与统计显示，避免无效进度条提示。
- 登录自定义背景逻辑继承：修正登录壁纸在自定义与默认图源间的继承策略，避免覆盖自定义设定。
- 前端与内嵌快照全面同步：重新编译 Vite 前端并同步打包至 Go 内嵌二进制资产。

### 影响与兼容性
- 控制端主程序与前端控制台版本统一升级至 v0.6.27，API Contract 保持为 1。
- 数据库结构向下兼容，已有外观设置及用户配置完全无缝兼容。
- 现有节点监控、DDNS 与转发配置不受影响，保持高效稳定运行。

## 更新版本
- 裸机与 systemd 服务：使用面板内置在线更新或运行更新脚本升至 v0.6.27，数据目录及现有配置自动保留。
- Docker 容器部署：拉取并使用 ghcr.io/violetaini/relaydock:0.6.27，映射既有数据卷即可。
- 独立前端部署：采用配套 release bundle 中的 relaydock-web.tar.gz 替换 Web 静态资源。

## 操作方法
1. 管理员进入「系统设置」，在外观配置中可自由挑选默认壁纸（Bing、内置壁纸库）或自定义壁纸 URL。
2. 公开探针与登录页支持独立或共享外观背景图源，保存后即时生效。
3. 服务器卡片对不限流量节点自动隐藏或调整剩余进度指示，视觉更为清爽统一。

## 验证
- 前端单测全数通过，覆盖登录页外观背景与公开探针壁纸继承逻辑。
- 后端 internal/handler、internal/storage 与 internal/web 单元测试通过。
- 嵌入式前端资源静态健全性检验通过。
