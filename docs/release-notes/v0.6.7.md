# 更新日志

## v0.6.7 (2026-08-02)

### 本次更新
- 🛠️ 修复旧版独立安装通过面板成功升级后，因缺少产品状态记录而可能再次提示完整更新的问题。
- 🔒 仅在当前控制端程序与官方 Release 的大小和 SHA-256 完全一致时，才补写嵌入式网页的产品状态。
- 📋 Guard、Agent 和测速安装资产只有在已配置且全部校验通过时才会被记录；未验证资产会保持待完整更新状态。
- 📝 GitHub Release 改为发布随标签提交的中文更新说明，明确列出更新内容、兼容性、更新路径与已完成验证。

### 影响与兼容性
- 此兼容引导仅适用于没有 `ARCWAY_WEB_ROOT` 的嵌入式独立部署；受管或普通外置前端不会被错误标记为已更新。
- 独立安装可继续使用面板完成完整产品更新；Docker 不支持容器内原地更新。
- 不包含数据库迁移，也不修改现有节点、订阅或 Agent 配置。

## 更新版本
- 裸机 / systemd：在面板“系统设置 → 系统更新”检查 `v0.6.7` 后确认更新。
- Docker：在宿主机执行 `docker compose pull && docker compose up -d`。

## 操作方法
1. 先阅读本版本的兼容性说明并确认当前部署方式。
2. 裸机 / systemd 部署在面板检查更新后执行完整更新，等待事务显示完成。
3. Docker 部署在宿主机拉取并重建镜像，不要在容器内点击原地更新。

## 验证
- 发布前已通过后端完整测试、发布说明契约测试、发布事务前置检查和代码格式校验。
- 独立安装的 `v0.6.4` 到 `v0.6.6` 面板升级已在两台 AMD64 与两台 ARM64 隔离服务器成功验证；`v0.6.7` 发布资产将继续按相同路径复测。
