# 更新日志

## v0.6.24 (2026-11-20)

### 本次更新
- 认证优化：登录接口明确区分禁用状态与凭据错误；停用账号在密码正确时准确提示“账号已被停用”，不再误报为“账号或密码错误”。
- 邮箱登录规范化：邮箱账号登录时执行规范化匹配，保证不同大小写输入下正确解析用户状态与禁用策略。
- 节点转发管理：转发节点支持直接选择现有目标节点并即时预览继承配置，支持安全切换受管目标并具备回滚机制。
- 动态域名与转发同步：支持持久化 DDNS 转发地址覆盖，配置保存后原子同步至服务器管理节点域名；分享链接生成优先采用当前服务器域名。
- 界面体验改善：放大节点分享二维码弹窗与可读链接展示面板，优化高分屏与移动端扫描识别率。
- 核心测试加固：修复单元测试在 Linux 下因临时路径超过 108 字节限制引发的 UNIX socket 绑定异常。
- Agent 组件升级：发布流水线同步集成 RelayDock Agent v0.4.12，支持自定义安装路径下的平滑升级。

### 影响与兼容性
- 控制端主程序与前端控制台版本统一升级至 v0.6.24，API Contract 保持为 1。
- 数据库结构向下兼容，已有节点、转发规则、用户凭据与品牌设置完整保留，无需重置或重新配置。
- 远程节点 Agent 无需强制立即升级，v0.4.11 及以上版本仍可正常通信；如需平滑支持自定义路径升级，可在面板中更新至 v0.4.12。

## 更新版本
- 裸机与 systemd 服务：使用面板内置在线更新或运行更新脚本升至 v0.6.24，数据目录及现有配置自动保留。
- Docker 容器部署：拉取并使用 ghcr.io/violetaini/relaydock:0.6.24，映射既有数据卷即可。
- 独立前端部署：采用配套 release bundle 中的 relaydock-web.tar.gz 替换 Web 静态资源。

## 操作方法
1. 管理员登录控制台，在「系统维护 → 版本与升级」中可查看并执行最新版本更新。
2. 在「用户管理」中停用的账号，登录时将直观收到停用提示；如需恢复可由管理员在后台重新启用。
3. 在「节点管理」中配置转发或 AnyDoor 节点时，可通过目标选择器快速继承现有节点配置并核对域名同步状态。
