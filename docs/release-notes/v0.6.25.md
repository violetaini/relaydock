# 更新日志

## v0.6.25 (2026-11-20)

### 本次更新
- 域名与 DDNS 交互深度重构：将节点域名与 DDNS 域名合二为一，消除多重域名输入的割裂感。
- 解析模式清晰化：明确提供「输入现成域名」与「启用本面板 DDNS 服务的域名」双选模式，按需展示配置项。
- 消除自动模式困惑：彻底移除晦涩的“自动模式”及“自动（按证书）”模糊描述，直接显示匹配到的已签发证书域名（如 *.example.com）及其关联 DNS 服务商；未匹配证书时明确提示选择具体 DNS 服务商。
- 动态提示感应：选择具体 DNS 服务商（如华为云、Cloudflare、DNSPod 等）时，即时显示该服务商将自动更新的目标域名。
- DDNS 状态面板优化：DDNS 概览面板中直接显示绑定的证书域名与更新域名，不再显示“自动（按证书）”。
- 后端与引擎同步：优化 DDNS 状态接口并返回匹配的证书域名；服务端创建与更新远程服务器时支持统一域名，并保持与底层 PullAddress 兼容。

### 影响与兼容性
- 控制端主程序与前端控制台版本统一升级至 v0.6.25，API Contract 保持为 1。
- 数据库结构向下兼容，已有服务器记录的 Domain 与 PullAddress 自动兼容，无需手动迁移。
- 原有的 DDNS 同步任务与心跳触发机制无缝衔接，继续支持双栈 IPv4/IPv6 动态解析。

## 更新版本
- 裸机与 systemd 服务：使用面板内置在线更新或运行更新脚本升至 v0.6.25，数据目录及现有配置自动保留。
- Docker 容器部署：拉取并使用 ghcr.io/violetaini/relaydock:0.6.25，映射既有数据卷即可。
- 独立前端部署：采用配套 release bundle 中的 relaydock-web.tar.gz 替换 Web 静态资源。

## 操作方法
1. 管理员进入「服务器管理」，点击「添加服务器」或编辑现有服务器。
2. 在「高级与网络选项」中，可根据需求选择「输入现成域名」或「启用本面板 DDNS 服务的域名」。
3. 启用 DDNS 服务时，可在下拉列表中直接选择已签发证书的域名或具体的 DNS 提供商（如华为云、Cloudflare 等），下方将即时显示解析同步详情。
